# 🔐 Custom RSA Cryptosystem & Digital Signature Tool

Десктопное приложение с графическим интерфейсом (GUI) для генерации криптографических ключей, формирования и верификации электронных цифровых подписей (ЭЦП) любых файлов.

Главная особенность проекта — **собственная реализация математического аппарата RSA** на чистом Python без использования готовых криптографических библиотек (`cryptography`, `rsa`, `PyCryptodome`).

---

## 📌 Архитектура и математический аппарат

Приложение реализует классическую схему асимметричного шифрования с открытым ключом RSA и алгоритм цифровой подписи на базе хеш-функции **SHA-256**.

### 1. Вероятностный тест простоты Миллера — Рабина
Для генерации криптостойких простых чисел $p$ и $q$ реализован тест Миллера — Рабина с числом раундов $k = 40$, что обеспечивает вероятность ошибки генерации составного числа менее $4^{-40} \approx 10^{-24}$:
* Представление $n - 1 = 2^r \cdot d$.
* Проверка условий свидетелей простоты через быстрое модульное возведение в степень.

### 2. Генерация ключевой пары (Key Generation)
* Вычисление модуля $n = p \cdot q$ и функции Эйлера $\phi(n) = (p - 1)(q - 1)$.
* Выбор открытой экспоненты $e$ ($\gcd(e, \phi(n)) = 1$).
* Нахождение секретной экспоненты $d$ как мультипликативного обратного:  
  $$d \equiv e^{-1} \pmod{\phi(n)}$$
  *(через расширенный алгоритм Евклида)*.
* Сохранение ключей в структурированные файлы `public.key` $(e, n)$ и `private.key` $(d, n)$.

### 3. Механизм формирования и проверки подписи
* **Хеширование:** вычисление 256-битного дайджеста файла блоками по 4 КБ для эффективной обработки файлов любого размера.
* **Подписание (Sign):** возведение хеша $H$ в степень секретной экспоненты $d$ по модулю $n$:  
  $$S = H^d \pmod n$$
  Подпись сериализуется в HEX-строку и сохраняется в файл с расширением `.sig`.
* **Верификация (Verify):** расшифрование подписи открытым ключом адресата:  
  $$H' = S^e \pmod n$$
  Если вычисленный $H'$ совпадает с оригинальным хешем проверяемого файла, гарантируется **целостность данных** и **неотрекаемость авторства**.

## 🖥 Пользовательский интерфейс (GUI)

Десктопный интерфейс построен на нативной библиотеке **Tkinter** и разделен на 4 логических шага:
1. **Генерация ключей:** выбор битовой длины ключа (от 512 до 4096 бит) и экспорт ключевой пары.
2. **Выбор файла:** встроенный проводник для выбора целевого документа любого формата.
3. **Создание подписи:** генерация открепленной подписи в формате `.sig`.
4. **Проверка подписи:** валидация документа с выводом модального окна о валидности/компрометации данных.

* **Язык:** Python 3.9+

* **Криптография и математика:** `hashlib` (только для вычисления SHA-256), модуль `random`, целочисленная арифметика больших чисел произвольной точности (Python BigInt).

```bash
cd custom-rsa-digital-signature
```

Проект использует только стандартную библиотеку Python и **не требует установки внешних pip-зависимостей**:

```bash
python rsa-digital-signature-tool.py
```

## 📋 Инструкция по использованию

1. В блоке **«1. Генерация и сохранение ключей»** укажите битовую длину (по умолчанию: `2048`) и нажмите **Генерировать**. Рядом со скриптом появятся файлы `public.key` и `private.key`.
2. В блоке **«2. Выбор файла»** выберите файл, который хотите подписать (например, `contract.pdf`).
3. Нажмите кнопку **«Создать подпись (.sig)»**. Будет создан файл `contract.pdf.sig`.
4. Для проверки подлинности выберите файл и нажмите **«Проверить подпись»**. Если содержимое файла изменить хотя бы на один байт — система уведомит о компрометации документа:
   * ✅ *«Подпись действительна! Файл не был изменен.»*
   * ❌ *«Подпись недействительна! Файл был изменен или использован неверный ключ.»*

## ⚠️ Дисклеймер безопасности (Security Note)

Проект создан в учебно-демонстрационных целях для визуализации работы математических примитивов асимметричной криптографии. В продакшен-системах рекомендуется использовать сертифицированные библиотеки (OpenSSL / libsodium) с защитой от атак по сторонним каналам (Side-Channel Timing Attacks) и padding-схемами (OAEP / PSS).
